# Data acquisition checklist

The package intentionally does not bundle real external GIS datasets.

Use these official/authoritative starting points and verify current access conditions:

1. Survey of India Online Maps:
   https://onlinemaps.surveyofindia.gov.in/

2. BMC GIS / BMC-on-Map:
   https://portal.mcgm.gov.in/irj/portal/anonymous/BMC-on-Map-NearMe-Amenities-Facilities

3. BharAtlas/OpenCity Mumbai wards:
   https://bharatlas.com/view/wards_mumbai

4. Mumbai Police map:
   https://mumbaipolice.gov.in/Police_map

5. Geofabrik India OSM:
   https://download.geofabrik.de/asia/india.html

6. Census of India:
   https://censusindia.gov.in/nada/

7. WorldPop:
   https://hub.worldpop.org/geodata/

8. Bhuvan:
   https://bhuvan-app1.nrsc.gov.in/bhuvan2d/bhuvan/bhuvan2d.php

9. Copernicus DEM:
   https://documentation.dataspace.copernicus.eu/APIs/SentinelHub/Data/DEM.html

For each source, save:
- source URL
- date accessed
- downloaded file name
- version/date of dataset
- license
- processing steps

Do not scrape or redistribute restricted data simply because a website displays it.
