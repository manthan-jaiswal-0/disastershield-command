# DisasterShield Command

Create a professional, production-quality frontend for "DisasterShield" — an intelligent disaster management and emergency response platform.

The product should feel like a real-world command and coordination system used by disaster management authorities, not an AI demo or hackathon template.

Design a complete interface around the workflow:

Detect → Verify → Assess → Prioritize → Decide → Respond → Monitor → Resolve.

Include:

- Authority command dashboard with live incident overview

- Interactive disaster map view

- Incident cards showing verification confidence, risk level, affected population, and priority (P1/P2/P3)

- Incident details page showing evidence sources, timeline, recommended actions, assigned resources, and current status

- Resource coordination view for rescue teams, hospitals, shelters, and emergency vehicles

- Citizen-facing emergency reporting and alert interface

- Responder view for assigned incidents and status updates

The interface should communicate trust, clarity, and urgency. Keep information hierarchy strong so emergency decisions can be made quickly.

Avoid:

- Generic AI dashboard aesthetics

- Excessive glowing effects, gradients, futuristic elements, or unnecessary animations

- Overly rounded card-heavy layouts

- Anything that looks obviously generated by AI

Make it feel similar to a refined government/emergency operations product but with a modern, clean user experience. Use subtle visual details, strong typography, meaningful data visualization, and a polished professional layout.

Prioritize usability, realism, and demo impact. A judge should immediately understand the problem, workflow, and value of DisasterShield within a few minutes.
